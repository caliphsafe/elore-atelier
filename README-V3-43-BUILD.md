- Explicit sitewide foreground/background contrast system.

- Olive is the default dark foreground; bone is the default light foreground.
- Added safe button variants with readable default and hover states.
- Rebuilt Experiences as an invitation-to-book journey using approved content, materials imagery, video, workshop formats, included items, and the existing booking form.
- Rebuilt Custom as a six-stage editorial commission journey and retained the approved custom title/description, fit guidance, assistance email, and temporary video link.
- Refined About principles section into a rectangular editorial layout with olive text throughout.
- Pushed Home and Shop toward a fashion-editorial/catalogue composition with varied scale and less card styling.
- Removed Lookbook route and unused Lookbook component.
- No package-lock.json included.
