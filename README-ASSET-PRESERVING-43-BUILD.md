# ELÖRE Atelier — Asset-Preserving Cultural Luxury 43 Build

This rebuild is intentionally based on the latest recovered ELÖRE project and its subsequent Home, Shop/About, Atelier, and Experiences patches.

## Non-negotiable preservation rule
This package does **not** replace ELÖRE photography. All existing page image paths remain the source of truth, including Home, About, Atelier, Experiences, Lookbook, Custom, Contact and Shopify product media. The new direction is achieved through layout, crop behavior, scale, color fields, typography, spacing, motion and composition.

When merging this build into the live repository, retain the actual existing files inside `public/images/**` and `public/videos/**`. The recovered historical 43 Build packages stored image folders as placeholders, so this ZIP intentionally preserves the exact existing asset references rather than inventing replacement photography.
